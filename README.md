# 宛名ラベル印刷

Excelの住所録から、市販のラベル用紙に宛名を印刷するためのツールです。
ブラウザだけで動き、入力した住所録を外部に送ったり保存したりしません。

公開ページ：https://miya096jp.github.io/address_printer/

## 使い方

1. **住所録を入れる**
   - 「ひな形CSVをダウンロード」で、列がそろったひな形を取得できます
   - CSVファイルを選ぶか、Excelの表を見出しの行ごとコピーして貼り付けます
   - 文字コードは UTF-8 と Shift_JIS のどちらでも読み込めます
   - 列名がひな形と違うときは、どの列が何にあたるかを選ぶ画面が出ます
   - 一覧のチェックボックスで、印刷する宛先を選べます
2. **用紙を選ぶ**
   - A4 12面・24面か、カスタム（寸法をmmで入力）を選びます
   - 試し刷りでずれていたら、0.5mm単位で位置を調整します
   - 使いかけの用紙には、「印刷を始める位置」で空いているラベルを選びます
3. **印刷する**
   - 印刷画面で、倍率を **100%**、余白を **「なし」** にしてください
   - はじめは「枠線を印刷する」をオンにして、普通紙で試し刷りすることをおすすめします

### 住所録の列

| 列                  | 例                    | メモ                                                   |
| ------------------- | --------------------- | ------------------------------------------------------ |
| 郵便番号            | 123-4567              | 全角やハイフンなしでも「〒123-4567」にそろえます       |
| 住所1               | 見本県見本市中央1-2-3 | 必須                                                   |
| 住所2（建物名など） | 見本ビル5階           |                                                        |
| 会社名              | 見本商事株式会社      |                                                        |
| 部署名              | 営業部                |                                                        |
| 役職                | 部長                  | 部署名と同じ行に並べます                               |
| 氏名                | 山田 太郎             | 氏名・会社名・部署名のどれか1つは必須                  |
| 敬称                | 先生                  | 空なら、氏名があれば「様」、なければ最後の行に「御中」 |

試せるサンプルが `samples/` にあります（すべて架空の住所です）。

## ラベル寸法の出典

| 用紙    | ラベルの大きさ | 列×行 | 上余白 | 左余白 | 間隔 |
| ------- | -------------- | ----- | ------ | ------ | ---- |
| A4 12面 | 86.4 × 42.3mm  | 2 × 6 | 21.2mm | 18.6mm | なし |
| A4 24面 | 66 × 33.9mm    | 3 × 8 | 12.9mm | 6mm    | なし |

- **ラベルの大きさと列×行**：各メーカーの製品ページ
  - エーワン 72212（12面）：https://www.a-one.co.jp/product/search/detail.php?id=72212
  - ヒサゴ ELM008（12面）：https://www.hisago.co.jp/products/elm008/
  - エーワン 72224（24面）：https://www.a-one.co.jp/product/search/detail.php?id=72224
- **上余白と左余白**：メーカーの製品ページには載っていなかったため、オープンソースのラベル印刷ソフト gLabels に収録されているヒサゴ ELM008 / ELM012 の値を使っています
  - https://github.com/jimevins/glabels-qt/blob/master/templates/hisago-templates.xml

同じ大きさの他社製品も同じ並びだと考えていますが、メーカーの公式な値では確かめられていません。
使う用紙で一度試し刷りをして、ずれていれば「印刷位置の微調整」で合わせてください。

用紙を追加するときは、`src/lib/labelLayouts.ts` の `labelProducts` に1件足します。

## データの扱いとセキュリティ

- 入力した住所録は、ブラウザのメモリ上でだけ扱います。サーバーへの送信、localStorage・IndexedDB・Cookie への保存はしません
  - ESLint のルールで、ストレージや通信を使うコードを書けないようにしています（`eslint.config.js`）
  - 本番のビルドには Content Security Policy を入れ、外部への通信（`connect-src 'none'`）をブラウザの機能で禁止しています（`vite.config.ts`）
- フォントはアプリに同梱し、外部のCDNやアクセス解析は使いません
- 依存ライブラリは Dependabot で更新を受け取り、CI で `npm audit` を実行しています

このツールでは防げないこともあります。

- 印刷画面で「PDFに保存」したファイルや、ブラウザの拡張機能が読み取る内容は、このツールの外で扱われます
- GitHub Pages ではレスポンスヘッダーを設定できないため、他のサイトへの埋め込みを禁止する `frame-ancestors` は使えません。このツールにはサーバーへ送る操作がないため、影響は小さいと判断しています

## 開発

Node.js 24 を使います。

```sh
npm install
npm run dev      # 開発サーバー
npm run check    # 静的チェック・整形の確認・型チェック・テストをまとめて実行
npm run build    # 本番用のビルド（dist/）
npm run preview  # ビルドしたものを手元で確かめる
```

- 画面と処理を分けています。CSVの読み込みやラベル配置の計算などは `src/lib/` にあり、React に依存しません
- フッターのモニターページのURLは `src/constants.ts` にあります

## デプロイ

`main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy.yml`）がテストとビルドを行い、GitHub Pages に公開します。

初めて設定するときは、リポジトリの Settings → Pages で、Source を「GitHub Actions」にしてください。
リポジトリ名を変えたときは、`vite.config.ts` の `base` も合わせて変えてください。
